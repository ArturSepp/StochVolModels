# stochvolmodels.fitters

*Author: [Artur Sepp](https://github.com/ArturSepp)*

Implemented in [StochVolModels](https://github.com/ArturSepp/StochVolModels). Software citation [CITATION.cff](../../../CITATION.cff).

Estimate parameters from market quotes, infer local volatility or leverage, and measure residuals and surface consistency. diagnose_fit returns a DiagnosticReport in the caller's price units.

[Parent package guide](../README.md).

- [adapters](adapters/README.md) — Convert native quotes or optional OptionChainAnalytics observations into aligned calibration and diagnostic inputs.
