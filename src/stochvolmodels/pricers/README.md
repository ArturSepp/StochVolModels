# stochvolmodels.pricers

*Author: [Artur Sepp](https://github.com/ArturSepp)*

Implemented in [StochVolModels](https://github.com/ArturSepp/StochVolModels). Software citation [CITATION.cff](../../../CITATION.cff).

Combine a model with an instrument and valuation method. ModelPricer derives slice and single-option helpers from price_chain.

[Parent package guide](../README.md).

- [factor_hjm](factor_hjm/README.md) — Experimental factor HJM rate curves, affine expansions and Monte Carlo.
- [logsv](logsv/README.md) — Historical import paths for the LogSV parameters, affine expansion, moments and backbone fitter.
- [rough_logsv](rough_logsv/README.md) — Compatibility imports for experimental rough LogSV controls, pricing and split-step simulation.
- [tdist](tdist/README.md) — Value European contracts under the Student-t terminal law and invert premiums to implied volatility.
