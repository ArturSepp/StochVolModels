# Barrier options with stochastic volatility

*Author: [Artur Sepp](https://github.com/ArturSepp)*

Implemented in [stochvolmodels](https://github.com/ArturSepp/StochVolModels).
Software citation: [CITATION.cff](https://github.com/ArturSepp/StochVolModels/blob/main/CITATION.cff).

Companion material for Alexander Lipton and Artur Sepp, **Toward an efficient hybrid
method for pricing barrier options on assets with stochastic volatility**, *Wilmott*
(2022). The method conditions on simulated volatility paths and solves the conditional
barrier problem using heat potentials, with finite differences and Monte Carlo as
comparisons. [Public preprint](https://arxiv.org/abs/2202.07849).

## Contents

| Directory | Contents |
|---|---|
| [`paper/`](paper/README.md) | Latest locally available author LaTeX (15 February 2022), compiled [PDF](paper/HestonPaper.pdf), 20 original image assets for 11 figures, and a build script. |
| [`replication/`](replication/) | Python figure workflows, conditional pricing kernels, Monte Carlo simulation, and numerical verification. |

The manuscript is the author's available source version; it is not the publisher's
typeset PDF. The included figures are the original archived assets, not outputs
regenerated by this reorganization. Their filenames and the historical Python runner's
output names do not always correspond one to one.

## Run the replication

Run from the repository root with its configured Python interpreter and the
`research` extra installed. On this Windows host, use the external interpreter specified
in the repository's [AGENTS.md](../../AGENTS.md); do not create an environment in OneDrive.

```console
python -m papers.barrier_options_sv_wilmott_2022.replication.verify_pde --output agents/barrier_pde.json
python -m papers.barrier_options_sv_wilmott_2022.replication.article_figures
```

The figure driver selects a case through `Locals` / `run_local` and defaults to the
down-and-out call comparison. Other cases cover conditional drift and variance, Green
densities, and survival. It writes figures through `stochvolmodels.local_path`, using
the configured output directory. It uses simulated paths and requires no external
market dataset. The full figure settings use substantial Monte Carlo batches.

The verification command checks historical time partitions, survival and boundary
behavior, and independent Volterra/reflection comparisons. Add `--path-batches` to run
the larger original Green, survival and call batches as well.

| Module | Role |
|---|---|
| [`article_figures.py`](replication/article_figures.py) | Main figure driver and original conditional PDE pricing. |
| [`green_solutions.py`](replication/green_solutions.py), [`pde.py`](replication/pde.py) | Historical conditional Green functions, survival and finite-difference kernels. |
| [`mc_volterra.py`](replication/mc_volterra.py), [`volterra.py`](replication/volterra.py) | Heat-potential/Volterra valuation and supporting comparisons. |
| [`mc_engine.py`](replication/mc_engine.py) | Heston decomposition and Monte Carlo paths. |
| [`analytic.py`](replication/analytic.py), [`utils.py`](replication/utils.py) | Analytic benchmark and shared numerical helpers used by the workflows. |
| [`pde_adapter.py`](replication/pde_adapter.py), [`verify_pde.py`](replication/verify_pde.py) | Conditional adapter to the public 1D PDE engine and its verification. |

The figure driver's default survival calculation preserves the historical time
partition. The optional `pde_engine="adapter"` with `partition="full"` includes the
earliest time interval; see the [barrier verification notes](../README.md#barrier-pde-verification).
Moving these modules did not change their numerical code or random seeds.

## Build the manuscript

```console
python papers/barrier_options_sv_wilmott_2022/paper/build_paper.py
```

This requires pdfLaTeX from MiKTeX or TeX Live and writes the PDF beside the source.
The build uses three passes in a temporary directory and rejects missing references,
duplicate labels and margin overflows. See the [source and build notes](paper/README.md).
